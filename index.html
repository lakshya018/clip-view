ClipView

A minimal, fast, and elegant clipboard history manager for macOS. Keep your last copied items within reach, without the Dock clutter.

Menu bar access Option + Space 20 to 100 items

History

Capture recent clips.

Quick start

Copy the command and paste it into Terminal.

Terminal 
TMP_DIR=$(mktemp -d) &&
git clone https://github.com/lakshya018/clip-view.git "$TMP_DIR" &&
cd "$TMP_DIR" &&
curl -O https://download.swift.org/swiftly/darwin/swiftly.pkg &&
installer -pkg swiftly.pkg -target CurrentUserHomeDirectory &&
yes Y | ~/.swiftly/bin/swiftly init --no-modify-profile &&
export PATH="$HOME/.swiftly/bin:$PATH" &&
swift build &&
mkdir -p ~/ClipView.app/Contents/MacOS &&
cp .build/debug/ClipView ~/ClipView.app/Contents/MacOS/ &&
cp Info.plist ~/ClipView.app/Contents/ &&
echo "ClipView built successfully and placed in ~/ClipView.app" &&
rm -rf ~/.swiftly &&
rm -rf ~/Library/Developer/Toolchains/swift* &&
rm -rf "$TMP_DIR" &&
cd ~
